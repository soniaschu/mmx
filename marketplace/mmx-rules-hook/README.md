# MMX Rules Guard (Marketplace copy)

This folder is prepared for a local MiniMax marketplace directory.

Place the folder directly under the active local marketplace directory, then enable it via `mcode plugin enable mmx-rules-hook@local`.

Example:

```bash
cp -r marketplace/mmx-rules-hook ~/.minimax/plugins/
# or
cp -r marketplace/mmx-rules-hook ~/.minimax-<profile>/plugins/
```
